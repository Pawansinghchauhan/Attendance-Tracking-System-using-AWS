# Attendance Tracking System using AWS

A cloud-based automated attendance system built using AWS serverless architecture.

## 🚀 Features
- Image storage using Amazon S3
- Event-driven processing using AWS Lambda
- Attendance data stored in DynamoDB
- Email notifications using AWS SES

## 🛠 Tech Stack
AWS (S3, Lambda, DynamoDB, SES)
